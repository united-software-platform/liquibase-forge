# forge-plugin

Плагин Liquibase Forge для харнесов с маркетплейсами: навык `forge` с шаблонами его операций.
Сам CLI `forge` — отдельный инструмент: он ставится из релизного тега репозитория, в плагин
не входит и навыком лишь вызывается. Установка и первый запуск — в [README.md](../../README.md)
репозитория.

## Структура

| Путь | Назначение |
|------|------------|
| `.zcode-plugin/plugin.json` | Манифест плагина для ZCode |
| `.claude-plugin/plugin.json` | Зеркальный манифест для Claude Code; содержимое совпадает |
| `skills/forge/SKILL.md` | Навык `forge`: единственная точка входа LLM в операции модели и seed |
| `skills/forge/templates/` | Шаблоны беклогов операций: `forge-model`, `forge-apply`, `forge-seed`, `forge-seed-apply` |

В состав плагина входит только каталог навыка: тесты, документы и спецификации репозитория forge
в поставку не попадают.

## Зависимости

| Зависимость | Минимальная версия | Источник |
|-------------|--------------------|----------|
| `backlog` (плагин `formular`) | 1.4.0 | запись `backlog` маркетплейса `liquibase-forge`; запасной путь — маркетплейс `formular` |
| CLI `forge` | тот же тег, что плагин | релизный тег репозитория: `uv tool install` |

Навык порождает и исполняет беклоги навыками плагина `backlog`, а шаги беклога вызывает командой
`forge`. Перед работой навык проверяет, что CLI `backlog` и команда `forge` доступны, — иначе
останавливается с командой установки. CLI `backlog` ищется в `PATH`, затем в каталогах кеша
плагина ZCode и Claude Code; для найденного каталога навык задаёт `BACKLOG_HOME`.

Шаблоны операций лежат в плагине и в проект не копируются: навык передаёт их каталог команде
`backlog generate` ключом `--templates` и значением `templates` — значение записывается
во фронтматтер беклога операции, и беклог операции тем же каталогом порождает беклоги попыток.

## Совместимость с харнесами

- **ZCode и Claude Code** — плагин ставится из маркетплейса `liquibase-forge`: каталог лежит
  в `.claude-plugin/marketplace.json` в корне репозитория.
- **Харнес без маркетплейсов** — навык формата Agent Skills подключается ссылкой на каталог
  `skills/forge` в каталоге навыков харнеса.

## Что плагин меняет в проекте

Ничего, кроме файлов своей работы: следа операций в `backlog/`, локальных файлов в `.forge/`
и корня принятого состояния. Конфигурация, документы, `pyproject.toml`, `.gitignore` и `mise.toml`
проекта остаются его собственными — координаты и секреты forge владелец объявляет сам.

## Проверка

Состав плагина сверяют тесты репозитория:

```bash
mise run test -- tests/plugin
```
