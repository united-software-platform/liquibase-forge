## ADDED Requirements

### Requirement: Возврат строк данных подтверждается проверкой
Для changelog данных проверка возврата `forge rollback` MUST проверять строки по PK из changelog
попытки: вставленных строк нет (`row_absent`), удалённые есть со значениями из блока отката
(`row_present`), изменённые имеют значения из блока отката (`row_restored`). Результат SHALL
записываться в `rollback.json` наравне с проверками структуры.

#### Scenario: Вставка откатана
- **WHEN** откатывается попытка, changelog которой вставил строку `paid` в `order_status`
- **THEN** строки `paid` нет, `rollback.json` содержит пройденную проверку `row_absent` для неё

#### Scenario: Изменение не откатано
- **WHEN** после отката попытки, изменившей `title` строки `draft`, значение осталось новым
- **THEN** проверка `row_restored` для `draft` не пройдена, команда возвращает код `1`

#### Scenario: Запасной путь для данных
- **WHEN** откат changelog данных Liquibase завершился ошибкой
- **THEN** БД пересоздана, принятый `master.yaml` накатан вместе с принятыми changelog данных, проверки строк выполнены
