## MODIFIED Requirements

### Requirement: Интеграционные тесты исполняются в workflow
Workflow проверок MUST поднимать окружение интеграционных тестов — сервер БД `lbfr-db-test`, образ
Liquibase и раннер целей `make` — и исполнять тесты с маркером `integration` в том же прогоне тестов.
Пропуск интеграционного теста из-за отсутствия окружения MUST в workflow завершаться ошибкой, а не
пропуском. Тесты, которым нужен CLI `backlog`, MUST пропускаться в workflow с указанием причины.
Локально без окружения интеграционные тесты SHALL по-прежнему пропускаться с причиной.

#### Scenario: Интеграционные тесты в CI
- **WHEN** workflow запускает тесты на PR в `main`
- **THEN** тесты с маркером `integration` исполнены, ни один из них не пропущен, а тесты, которым нужен CLI `backlog`, отмечены пропущенными с причиной

#### Scenario: Окружение в CI не поднялось
- **WHEN** раннер или сервер БД в прогоне workflow недоступен
- **THEN** интеграционные тесты завершаются ошибкой, и прогон красный

#### Scenario: Локальный прогон без окружения
- **WHEN** тесты запущены без `FORGE_TEST_DB_HOST` и без раннера, и признак обязательности интеграционных тестов не задан
- **THEN** тесты с маркером `integration` отмечены пропущенными с причиной
