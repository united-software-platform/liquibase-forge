# Spec Delta

## ADDED Requirements

### Requirement: Релиз не выпускается без пройденных проверок
Перед любой записью сценарий релиза MUST прогнать workflow проверок на коммите, с которого
выпускается версия. Если проверки не пройдены, сценарий SHALL завершиться ошибкой, и `VERSION`,
коммит, тег и GitHub Release MUST NOT создаваться.

#### Scenario: Проверки красные
- **WHEN** сценарий запущен с разрядом `minor`, а на коммите `main` падает тест
- **THEN** сценарий завершается ошибкой, `VERSION` не изменён, тега и релиза нет

#### Scenario: Проверки зелёные
- **WHEN** сценарий запущен с разрядом `minor`, в `VERSION` записано `0.1.0`, и проверки пройдены
- **THEN** сценарий выпускает `0.2.0`: релизный коммит, тег `v0.2.0` и GitHub Release

### Requirement: Право записи есть только у шага выпуска
Право `contents: write` MUST принадлежать только job'у, который повышает версию, ставит тег
и публикует релиз. Проверки, вызванные сценарием релиза, SHALL исполняться с правом только
на чтение.

#### Scenario: Права сценария
- **WHEN** проверяется описание сценария релиза
- **THEN** право `contents: write` задано только job'у выпуска, а job проверок получает `contents: read`
