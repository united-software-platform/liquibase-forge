## ADDED Requirements

### Requirement: Релизный коммит проходит защиту main ключом развёртывания
Релизный сценарий MUST публиковать релизный коммит и тег в защищённую `main` через ключ
развёртывания репозитория с правом записи. Закрытая часть ключа MUST храниться только в секрете
Actions. Ключ развёртывания SHALL быть единственным субъектом, который обходит правила `main`.
GitHub Release MUST по-прежнему создаваться токеном прогона.

#### Scenario: Выпуск при защищённой main
- **WHEN** `main` защищена правилами, и сценарий запущен с разрядом `minor` из `0.2.0`
- **THEN** коммит `Релиз v0.3.0` и тег `v0.3.0` опубликованы в репозитории, а GitHub Release `v0.3.0` создан

#### Scenario: Проверки на релизном коммите
- **WHEN** сценарий опубликовал релизный коммит в `main`
- **THEN** на этом коммите запускается workflow проверок, как на любом push в `main`

#### Scenario: Секрета ключа нет
- **WHEN** секрет с ключом развёртывания не задан
- **THEN** сценарий завершается ошибкой до записи `VERSION`, и коммит, тег и релиз не создаются
