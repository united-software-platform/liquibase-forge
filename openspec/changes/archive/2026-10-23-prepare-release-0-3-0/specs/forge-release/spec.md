# Spec Delta

## ADDED Requirements

### Requirement: Релиз не выпускается с открытыми задачами выпуска
Перед любой записью сценарий релиза MUST найти на GitHub milestone с названием `vX.Y.Z` нового
номера. Если такого milestone нет либо в нём есть открытая задача, сценарий SHALL завершиться
ошибкой, и `VERSION`, коммит, тег и GitHub Release MUST NOT создаваться. Сообщение SHALL называть
отсутствующий milestone или номера и заголовки открытых задач. Для чтения задач job выпуска
SHALL иметь право `issues: read`.

#### Scenario: Открытая задача в milestone
- **WHEN** сценарий запущен с разрядом `minor` при `VERSION` `0.2.0`, а в milestone `v0.3.0` открыта задача #7
- **THEN** сценарий завершается ошибкой, называет #7, `VERSION` не изменён, тега и релиза нет

#### Scenario: Milestone нет
- **WHEN** сценарий запущен с разрядом `patch` при `VERSION` `0.3.0`, а milestone `v0.3.1` не заведён
- **THEN** сценарий завершается ошибкой, называет `v0.3.1`, и ничего не записывается

#### Scenario: Все задачи закрыты
- **WHEN** сценарий запущен с разрядом `minor` при `VERSION` `0.2.0`, и все задачи milestone `v0.3.0` закрыты
- **THEN** гейт пройден, и сценарий выпускает `0.3.0`
