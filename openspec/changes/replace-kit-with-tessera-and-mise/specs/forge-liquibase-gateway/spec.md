# Spec Delta

## MODIFIED Requirements

### Requirement: Целевая БД входит в перечень тестовых

Шлюз MUST сверять хост, порт и имя БД с перечнем `FORGE_TEST_DB_ALLOWLIST` — записями
`хост:порт/имя` через запятую. `*` целиком на месте имени разрешает любую БД сервера;
звёздочка в конце имени — любую БД, чьё имя начинается с префикса. БД вне перечня и пустой
перечень SHALL давать отказ с кодом `2` без запуска Liquibase.

#### Scenario: БД вне перечня

- **WHEN** запрос называет БД, не совпадающую ни с одной записью перечня
- **THEN** Liquibase не запускается, исход содержит код `2` и указание на БД вне перечня

#### Scenario: Пустой перечень

- **WHEN** `FORGE_TEST_DB_ALLOWLIST` не задан либо пуст
- **THEN** любой запрос отклоняется с кодом `2`: БД не считается тестовой по умолчанию

#### Scenario: Подстановка имени БД

- **WHEN** перечень содержит `localhost:5432/*`, а запрос называет БД `t_0001` на `localhost:5432`
- **THEN** проверка перечня пройдена

#### Scenario: Подстановка префикса

- **WHEN** перечень содержит `localhost:5432/t_*`, а запрос называет БД `t_0001` на `localhost:5432`
- **THEN** проверка перечня пройдена

#### Scenario: Соседняя база вне префикса

- **WHEN** перечень содержит только `localhost:5432/t_*`, а запрос называет БД `shop` на `localhost:5432`
- **THEN** Liquibase не запускается, исход содержит код `2`

#### Scenario: Звёздочка не в конце имени

- **WHEN** запись перечня содержит `*` не в конце имени, например `localhost:5432/t_*_x`
- **THEN** запрос отклоняется с кодом `2` с указанием на некорректную запись перечня

## REMOVED Requirements

### Requirement: Команда передаётся файлом запроса

**Reason**: Граница процессов «агент в контейнере → раннер → `make` → шлюз на хосте»
исчезла: CLI и шлюз работают в одном процессе на хосту, и файл запроса не нужен.

**Migration**: Параметры наката CLI передаёт шлюзу напрямую; переменные `AGENT_RUNNER_*`
удаляются из `.env` проекта.

### Requirement: Результат пишется файлом при любом исходе

**Reason**: Код исхода больше не искажают `make` и клиент раннера, поэтому файл результата
не нужен.

**Migration**: Исход возвращается команде `forge`; файлы `.forge/liquibase-request.json`
и `.forge/liquibase-result.json` удаляются из проектов.

### Requirement: Шлюз доступен агенту только через раннер

**Reason**: Раннер и его белый список были границей песочницы; агента в контейнере
больше нет.

**Migration**: Цели `make liquibase-update` и `make liquibase-rollback` удаляются вместе
с `Makefile`; шлюз вызывает сам CLI.

### Requirement: Changelog берётся только из проекта

**Reason**: Сценарий «Liquibase не может изменить проект» обещал режим «только чтение»
монтирования контейнера. Нативный Liquibase запускается с рабочим каталогом вне проекта,
и неизменность файлов проверяется, а не гарантируется монтированием.

**Migration**: Заменена требованием «Changelog читается только из проекта» в этом же изменении.

### Requirement: Каталог обмена скрыт от git

**Reason**: Обмена файлами больше нет; локальным остаётся каталог драйвера Liquibase.

**Migration**: Заменена требованием «Локальный каталог forge скрыт от git» в этом же изменении.

## ADDED Requirements

### Requirement: Changelog читается только из проекта

Путь changelog MUST быть относительным, разрешаться внутри корня проекта и указывать
на существующий файл. Иначе шлюз SHALL отказать с кодом `2`, не запуская Liquibase. Процесс
Liquibase MUST запускаться с рабочим каталогом вне проекта: проект для Liquibase — только
источник changelog.

#### Scenario: Путь выходит за корень проекта

- **WHEN** путь changelog абсолютный либо содержит переход `..` за пределы корня проекта
- **THEN** Liquibase не запускается, исход содержит код `2` и указание на недопустимый путь

#### Scenario: Файлы проекта не меняются Liquibase

- **WHEN** Liquibase исполняет накат
- **THEN** файлы проекта остаются неизменными, кроме файлов следа операции и принятого состояния, которые пишет сам `forge`

### Requirement: Локальный каталог forge скрыт от git

`forge` при записи локальных файлов в `.forge/` — драйвера Liquibase — MUST класть в каталог
`.forge/` файл `.gitignore` со строкой `*`, если такого файла там нет. Существующий
`.forge/.gitignore` SHALL NOT перезаписываться. `.gitignore` корня проекта при этом MUST NOT
меняться.

#### Scenario: Первая запись в каталог

- **WHEN** каталога `.forge/` нет, и `forge env up` загружает драйвер
- **THEN** появляются файл драйвера и `.forge/.gitignore` со строкой `*`, а `git status` проекта не показывает файлов `.forge/`

#### Scenario: Файл уже есть

- **WHEN** в `.forge/.gitignore` владелец записал собственные строки
- **THEN** после загрузки драйвера содержимое файла не изменилось

### Requirement: Liquibase запускается нативно с драйвером из локального каталога

Шлюз MUST запускать Liquibase исполняемым файлом из `PATH`, передавая драйвер PostgreSQL
из `.forge/lib/` элементом classpath. Контейнер и Docker Compose SHALL NOT использоваться.
Отсутствующий Liquibase или драйвер — отказ с кодом `2` без запуска.

#### Scenario: Состав команды

- **WHEN** выполняется накат
- **THEN** команда содержит `liquibase`, элемент classpath с путём драйвера из `.forge/lib/`, действие и путь changelog, а Docker в ней нет

#### Scenario: Liquibase не найден

- **WHEN** `liquibase` нет в `PATH`
- **THEN** шлюз отказывает с кодом `2`, и Liquibase не запускается

#### Scenario: Драйвер не найден

- **WHEN** в `.forge/lib/` нет файла драйвера
- **THEN** шлюз отказывает с кодом `2` и называет `forge env up`

### Requirement: Исход шлюза возвращается вызвавшей команде

Шлюз MUST возвращать исход команде `forge` без файлов обмена: успех Liquibase — код `0`
с выводом, ошибка Liquibase — код `1` с диагностикой, отказ до запуска — код `2` с причиной.

#### Scenario: Ошибка Liquibase

- **WHEN** Liquibase завершается ошибкой наката
- **THEN** исход содержит код `1` и диагностику Liquibase

#### Scenario: Отказ шлюза

- **WHEN** шлюз отказал до запуска Liquibase
- **THEN** исход содержит код `2` и причину, а файлов запроса и результата в `.forge/` нет

### Requirement: Учётные данные уходят Liquibase окружением

Адрес и учётные данные целевой БД шлюз MUST брать из `FORGE_DB_*` и передавать Liquibase
переменными окружения. Командная строка SHALL их не содержать.

#### Scenario: Пароль вне аргументов

- **WHEN** формируется команда Liquibase
- **THEN** пароль и имя пользователя отсутствуют в её аргументах

#### Scenario: Переменные не заданы

- **WHEN** не заданы `FORGE_DB_USER` или `FORGE_DB_PASSWORD`
- **THEN** шлюз отказывает с кодом `2`, и Liquibase не запускается
