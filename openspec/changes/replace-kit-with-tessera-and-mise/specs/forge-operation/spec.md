# Spec Delta

## REMOVED Requirements

### Requirement: Ошибка окружения приостанавливает операцию

**Reason**: Сценарий «Раннер недоступен при накате» описывает среду, которой больше нет,
а формулировка «любой команды» захватывала бы новые команды среды, которые операцию
не останавливают.

**Migration**: Заменена требованием «Ошибка окружения команды операции приостанавливает
операцию» в этом же изменении.

## ADDED Requirements

### Requirement: Ошибка окружения команды операции приостанавливает операцию

Код `2` команды операции `forge` MUST приводить к `forge stop` с диагностикой команды
в причине и SHALL NOT считаться неуспехом попытки. Повторный вызов навыка MUST продолжать
операцию с той же задачи. Команды среды `forge env check` и `forge env up` под это правило
не подпадают.

#### Scenario: Liquibase недоступен при накате

- **WHEN** `forge apply` возвращает код `2`, потому что Liquibase не найден
- **THEN** операция в статусе `stopped` с причиной от `forge apply`, вердикт попытки не записан, счёт попыток не изменился

#### Scenario: Ошибка команды среды

- **WHEN** `forge env check` возвращает код `2`, а операция открыта
- **THEN** статус операции прежний, а `forge stop` не вызывалась
