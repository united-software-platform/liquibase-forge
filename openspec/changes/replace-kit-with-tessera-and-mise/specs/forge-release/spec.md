# Spec Delta

## MODIFIED Requirements

### Requirement: Номер версии хранится в одном файле

Номер версии forge MUST храниться в файле `VERSION` в корне репозитория, одной строкой
вида `МАЖОР.МИНОР.ПАТЧ`. Сборка CLI SHALL брать версию пакета из `VERSION`. Ни `pyproject.toml`,
ни `uv.lock` MUST NOT содержать номер версии проекта. Повторять номер могут только манифесты
плагина и запись маркетплейса.

#### Scenario: Версия пакета из VERSION

- **WHEN** в `VERSION` записано `0.2.0`, и CLI собран из репозитория
- **THEN** метаданные установленного пакета `liquibase-forge` называют версию `0.2.0`

#### Scenario: Смена номера не трогает lock-файл

- **WHEN** номер в `VERSION` изменён, а остальные файлы нет
- **THEN** `uv lock --check` проходит, и запуск CLI с `--frozen` не требует обновления `uv.lock`

#### Scenario: Манифесты на теге

- **WHEN** выполнен переход к дереву тега `v0.2.0`
- **THEN** поле `version` обоих манифестов плагина и записи маркетплейса равно `0.2.0`

### Requirement: Релиз публикуется на GitHub

После публикации тега сценарий MUST опубликовать GitHub Release `vX.Y.Z` по этому тегу. После
выпуска последний опубликованный релиз репозитория SHALL указывать на новую версию.

#### Scenario: Последний релиз

- **WHEN** сценарий выпустил `0.2.0`
- **THEN** `releases/latest` репозитория указывает на тег `v0.2.0`, и установка CLI из релизного тега `v0.2.0` ставит эту версию

## ADDED Requirements

### Requirement: Гейт версии плагина

Перед любой записью сценарий MUST сверять поле `version` обоих манифестов плагина и записи
маркетплейса с выпускаемым номером. При расхождении сценарий SHALL завершиться ошибкой, назвать
файл, найденное и ожидаемое значения. Манифесты обновляет разработчик: сценарий их SHALL NOT
менять.

#### Scenario: Манифесты отстают

- **WHEN** сценарий выпускает `0.3.0`, а в манифесте плагина записано `0.2.0`
- **THEN** сценарий завершается ошибкой, называет манифест и оба номера, `VERSION` не изменён, тега и релиза нет

#### Scenario: Манифесты совпадают

- **WHEN** сценарий выпускает `0.3.0`, и в обоих манифестах плагина и записи маркетплейса записано `0.3.0`
- **THEN** гейт пройден, и сценарий выпускает `0.3.0`
