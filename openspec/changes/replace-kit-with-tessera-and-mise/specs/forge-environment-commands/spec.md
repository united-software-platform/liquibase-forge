# Spec Delta

## Purpose

Команды проверки и подготовки среды исполнения Liquibase Forge: соединение с целевой БД,
перечень тестовых БД, Liquibase с драйвером, корень принятого состояния, а также идемпотентное
создание целевой БД и загрузка драйвера.

## ADDED Requirements

### Requirement: Проверка среды повторяет проверки статуса

`forge env check` MUST выполнять те же четыре проверки среды, что `forge status`: `database`,
`allowlist`, `liquibase`, `accepted`. Команда SHALL печатать один JSON-объект с массивом
`checks` — по элементу `name`, `ok`, `message` на каждую проверку — и не останавливаться на
первой непройденной.

#### Scenario: Все проверки пройдены

- **WHEN** среда настроена: БД доступна и входит в перечень, Liquibase с драйвером на месте, корень принятого состояния корректен
- **THEN** команда возвращает код `0`, а в `checks` лежат четыре элемента с `ok: true`

#### Scenario: Одна проверка не пройдена

- **WHEN** целевая БД не принимает подключения, а остальные проверки проходят
- **THEN** команда возвращает код `2`, у элемента `database` `ok: false` и диагностика, у остальных трёх `ok: true`

### Requirement: Проверка liquibase находит Liquibase и драйвер

Проверка `liquibase` MUST находить исполняемый файл Liquibase в `PATH` и файл драйвера
PostgreSQL в `.forge/lib/`. Отсутствие любого из них SHALL давать непройденную проверку
с диагностикой, называющей способ устранения.

#### Scenario: Liquibase и драйвер на месте

- **WHEN** `liquibase` доступен в `PATH` и файл драйвера лежит в `.forge/lib/`
- **THEN** проверка пройдена, а её сообщение называет версию Liquibase

#### Scenario: Liquibase не установлен

- **WHEN** `liquibase` нет в `PATH`
- **THEN** проверка не пройдена, а её сообщение предлагает `mise install`

#### Scenario: Драйвер не загружен

- **WHEN** `liquibase` доступен, а файла драйвера в `.forge/lib/` нет
- **THEN** проверка не пройдена, а её сообщение предлагает `forge env up`

### Requirement: Подготовка среды создаёт целевую базу

`forge env up` MUST создавать на сервере `FORGE_DB_HOST:FORGE_DB_PORT` роль `FORGE_DB_USER`
с паролем `FORGE_DB_PASSWORD` и базу `FORGE_DB_NAME`, владельцем которой служит эта роль,
если их нет. Существующие роль и база SHALL оставаться без изменений. Соединение
администратора — `FORGE_DB_ADMIN_USER` и `FORGE_DB_ADMIN_PASSWORD`, а без них — учётные данные
целевой БД.

#### Scenario: Первый запуск

- **WHEN** роли `FORGE_DB_USER` и базы `FORGE_DB_NAME` на сервере нет
- **THEN** роль и база созданы, команда возвращает код `0`

#### Scenario: Повторный запуск

- **WHEN** в базе `FORGE_DB_NAME` есть таблица, и команда запущена повторно
- **THEN** команда возвращает код `0`, а таблица на месте

#### Scenario: Нет прав на создание

- **WHEN** учётные данные администратора не позволяют создавать роли и базы
- **THEN** команда возвращает код `2`, диагностика называет недостающее право, на сервере ничего не создано

### Requirement: Подготовка среды загружает драйвер Liquibase

`forge env up` MUST помещать драйвер PostgreSQL в `.forge/lib/`, если файла с верной
контрольной суммой там нет. Файл с неверной суммой SHALL заменяться, файл с верной —
не перезагружаться. Неудачная загрузка MUST давать код `2` и не оставлять файла.

#### Scenario: Драйвера нет

- **WHEN** в `.forge/lib/` нет файла драйвера
- **THEN** драйвер загружен, его контрольная сумма совпадает с закреплённой, команда возвращает код `0`

#### Scenario: Файл повреждён

- **WHEN** файл драйвера в `.forge/lib/` есть, но его контрольная сумма не совпадает
- **THEN** файл заменён загруженным заново

#### Scenario: Загрузка не удалась

- **WHEN** адрес драйвера недоступен
- **THEN** команда возвращает код `2`, файла драйвера в `.forge/lib/` нет

### Requirement: Версия драйвера закреплена и переопределяется парой

Версия драйвера и её контрольная сумма MUST быть закреплены в CLI. Переменная
`FORGE_LIQUIBASE_DRIVER_VERSION` SHALL задавать иную версию только вместе с
`FORGE_LIQUIBASE_DRIVER_SHA256`: версия без суммы — ошибка настроек, код `2`.

#### Scenario: Значения по умолчанию

- **WHEN** обе переменные не заданы
- **THEN** загружается закреплённая в CLI версия с закреплённой контрольной суммой

#### Scenario: Версия без суммы

- **WHEN** задана только `FORGE_LIQUIBASE_DRIVER_VERSION`
- **THEN** команда возвращает код `2`, и загрузка не начинается

### Requirement: Команды среды не участвуют в операции

`forge env check` и `forge env up` MUST менять только локальные файлы в `.forge/lib/` и
объекты на сервере: след операций, статусы операций и корень принятого состояния SHALL
оставаться без изменений, в том числе при коде `2`.

#### Scenario: Открытая операция

- **WHEN** открыта операция, и выполнены обе команды среды
- **THEN** статус операции и файлы её следа не изменились

#### Scenario: Ошибка среды при открытой операции

- **WHEN** `forge env check` возвращает код `2`, а операция открыта
- **THEN** статус операции прежний
