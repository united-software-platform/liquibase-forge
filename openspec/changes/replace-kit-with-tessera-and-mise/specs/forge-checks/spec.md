# Spec Delta

## MODIFIED Requirements

### Requirement: Проверки повторяют локальный прогон

Workflow MUST выполнять ровно задачи раздела «Проверки» `CONTRIBUTING.md`: `lint`,
`format-check`, `types` и `test` — задачами mise по `mise.toml`. Инструменты MUST ставиться
mise, без Docker. Зависимости Python SHALL устанавливаться по `uv.lock` без его обновления.

#### Scenario: Команда добавлена в CONTRIBUTING

- **WHEN** в разделе «Проверки» появляется задача mise, которой нет в workflow
- **THEN** тест репозитория на соответствие workflow и раздела падает

#### Scenario: Lock-файл расходится с pyproject.toml

- **WHEN** `pyproject.toml` изменён, а `uv.lock` нет
- **THEN** установка зависимостей завершается ошибкой, и проверки не проходят

#### Scenario: Docker в workflow нет

- **WHEN** проверяется текст workflow проверок
- **THEN** в нём нет вызовов `docker` и `docker compose`

### Requirement: Интеграционные тесты исполняются в workflow

Workflow MUST поднимать окружение интеграционных тестов — нативный сервер PostgreSQL образа
раннера и Liquibase с драйвером через mise — и исполнять тесты с маркером `integration` в том
же прогоне. Docker и раннер в workflow SHALL отсутствовать. Пропуск интеграционного теста без
окружения MUST завершаться ошибкой. Тесты, которым нужен CLI `backlog`, MUST пропускаться
с причиной. Локально без окружения такие тесты SHALL пропускаться с причиной.

#### Scenario: Интеграционные тесты в CI

- **WHEN** workflow запускает тесты на PR в `main`
- **THEN** тесты с маркером `integration` исполнены, ни один из них не пропущен, а тесты, которым нужен CLI `backlog`, отмечены пропущенными с причиной

#### Scenario: Окружение в CI не поднялось

- **WHEN** сервер БД или Liquibase в прогоне workflow недоступен
- **THEN** интеграционные тесты завершаются ошибкой, и прогон красный

#### Scenario: Локальный прогон без окружения

- **WHEN** тесты запущены без `FORGE_TEST_DB_HOST` и без Liquibase, и признак обязательности интеграционных тестов не задан
- **THEN** тесты с маркером `integration` отмечены пропущенными с причиной

#### Scenario: Раннера и Docker в workflow нет

- **WHEN** проверяется текст workflow проверок и скриптов окружения CI
- **THEN** в них нет запуска раннера и вызовов `docker`

## REMOVED Requirements

### Requirement: Любая непройденная проверка делает прогон красным

**Reason**: Сценарий «Превышение объёма секции Makefile» описывает проверку, которой больше
нет: `Makefile` заменён задачами mise, и объём секций проверять не на чем.

**Migration**: Заменена требованием «Любая непройденная задача делает прогон красным» в этом
же изменении.

## ADDED Requirements

### Requirement: Любая непройденная задача делает прогон красным

Workflow MUST завершаться ошибкой, если хотя бы одна задача проверок завершилась ненулевым
кодом. Задача SHALL NOT отключаться через `continue-on-error`.

#### Scenario: Ошибка линтера

- **WHEN** `ruff check` находит нарушение
- **THEN** прогон завершается ошибкой, и статус PR — красный

#### Scenario: Ошибка типов

- **WHEN** задача `types` находит нарушение типов
- **THEN** задача завершается кодом `1`, и прогон завершается ошибкой
